# 참고 자료 지도

프로젝트의 현재 동작과 실행 방법은 [프로젝트 소개](../README.md), 협업 규칙은
[AGENTS.md](../AGENTS.md), 운영 문서 목록은 [문서 지도](../docs/README.md)가 정본입니다.
참고 자료나 과거 지침을 현재 구현·운영 규칙으로 적용하지 않습니다.

| 자료 | 역할 | 공유 여부 |
| --- | --- | --- |
| [하네스 참고·과거 문서](harness/README.md) | 출처와 적용 상태를 표시한 보존 자료 | Git으로 공유 |
| `references/이정민/` | 사용자가 선택적으로 사용하는 개인 V3 하네스 | 로컬 유지, Git 미포함 |

개인 V3는 현재 경로에 그대로 둡니다. 개인 폴더와 로컬 skill이 없는 checkout도
공통 문서를 읽고 기여할 수 있어야 합니다. 개인 하네스 설치나 다운로드는
프로젝트 실행의 필수 단계가 아닙니다.

공유 참고 자료를 추가할 때는 소유자·출처·버전과 현재 적용 여부를 남깁니다.
현재 프로젝트의 설계 이력은 [HISTORY](../docs/HISTORY.md)에서 관리하며,
설계 참고 자료를 하네스 지침으로 분류하지 않습니다.
